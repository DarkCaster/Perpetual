# Custom langchaingo library variant with custom fixes needed for this project

This is trimmed down version of [langchaingo](https://github.com/tmc/langchaingo) library with some custom fixes for this project.

Unfortunately, original library development seem to be stopped some time ago, and when development does happen, it is very slow and does not cover my needs.

So, I decided to create a temporary fork of this library within my project and modify it to suit my needs. Over time, I'll try to leave only the bare minimum functionality required for my program to function, and then add any missing functions to the library. I may remove this library in future or switch to another library for LLM connection.
